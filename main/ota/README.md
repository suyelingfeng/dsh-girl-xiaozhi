# 固件升级与云端激活

`ota.cc/.h` 保留云端版本查询、设备激活、服务地址与时间配置。
`policy.h` 集中定义远程固件刷写策略。

当前实战派定制版本的 `CONFIG_ENABLE_REMOTE_FIRMWARE_OTA` 默认关闭，板卡构建配置也明确设为 `n`：

- 开机检查不触发固件安装。
- MCP 不注册 `self.upgrade_firmware`。
- 应用与底层升级函数在停止音频、HTTP 下载和 Flash 写入之前拒绝请求。
- USB 串口烧录继续可用。

关闭策略的中文注释保存在调用边界，原升级代码保留以便维护其他板型。
不要删除 `OTA_URL` 或整个 `CheckVersion()`：它们也用于激活和联网配置。
其他开发板的该配置默认开启，其原有行为保持兼容。
